# Analytics Depth V2 Roadmap

## Shipped foundation

- common versioned Decision Object;
- deterministic evidence provenance;
- known-answer experiment, panel, and MMM demos;
- corrected event-study fixed-effects specification;
- CUPED with raw/adjusted intervals, variance reduction, covariate balance, and pre-treatment guardrail;
- Native MMM V2 validation and conditional uncertainty.

## Next depth gates

CampaignLab should not call Analytics Depth V2 complete until the priority methods share:

1. a normalized analytical-result envelope;
2. explicit estimand and analysis-unit fields;
3. effect estimate and uncertainty;
4. assumption and integrity checks;
5. falsification or sensitivity checks where applicable;
6. decision thresholds and failure behavior;
7. known-answer recovery tests;
8. Decision Object adapters.

Planned additions include covariate-adjusted binary experiments, cluster-randomized inference, regression predictive holdouts, time-aware validation, causal sensitivity analysis, and stronger event-study pre-trend summaries.
